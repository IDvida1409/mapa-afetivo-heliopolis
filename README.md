# Mapa afetivo de Heliópolis

Formulário participativo para receber fotografias e relatos sobre lugares significativos de Heliópolis.

## Rodar localmente

```bash
npm install
npm start
```

Abra `http://localhost:3000`.

## Publicar no Render

Configure um Web Service Node com o comando `npm start`. Para não perder imagens quando o serviço reiniciar, configure um Persistent Disk e defina `UPLOAD_DIR` para o caminho montado. As contribuições ficam em `data/submissions.json` e precisam ser revisadas antes de qualquer publicação.
